## Regla de cierre
Ningun agente declara terminado el proyecto por volumen de trabajo. El cierre exige:
- 391/391 paginas o contenido equivalente preservado.
- DOC FINAL y NOTAS separados.
- PDF/HTML derivados de la misma fuente.
- Fotos/documentos nuevos integrados por evidencia, no por intuicion.
- PDFs legales insertables en una sola impresion definitiva.
- Vercel preview verificado.
- Release Auditor = PASS - LIBERABLE.

## Fuente canonica
- Master: ROCA_MASTER_WEB.pdf, 391 paginas.
- Correcciones posteriores explicitas del usuario prevalecen.
- ClickUp = seguimiento operativo.
- GitHub = fuente tecnica.
- Drive = evidencia/documentos pesados y sensibles.
