# ROCA TAX

Plataforma web oficial de ROCA TAX: sitio público, catálogo de formas, colección de taxidermia y administración editorial simplificada.

## Flujo de trabajo

- Linear: equipo `ROCA TAX`, issues `ROC-*`.
- GitHub: repositorio canónico `romerobarcenabraulio-hash/ROCA-TAX`.
- Vercel: proyecto `roca-tax`.
- Todo cambio posterior al bootstrap se desarrolla en una rama vinculada a un issue `ROC-*` y llega a `main` mediante pull request.

La arquitectura, la seguridad y el diseño se implementarán conforme al plan maestro aprobado antes de publicar contenido real.
