Qué evidencia cierra cada frente

FrenteEvidencia mínima útilNo demuestra por sí sola
ExtintoresFoto de ubicación + altura + señal + recorrido medido + identificación del equipo + registro/revisión aplicable.Clasificación de riesgo completa, entrenamiento o cobertura de todo el taller.
Salida / rutaRecorrido fotografiado + distancia medida + puerta operable + señal visible + tiempo cuando aplique.Plan de emergencia completo ni simulacro.
IluminaciónLectura lux + ubicación/plano de tarea + instrumento + fecha.Calidad visual de todas las tareas del área.
Químicos / HDSProducto real + etiqueta + HDS correspondiente + foto de almacenamiento + compatibilidad revisada.Exposición ocupacional, ventilación suficiente o clasificación del residuo.
Ventilación / extracciónProceso/producto + punto de generación + evaluación/medición aplicable + foto del control instalado.Eficacia sólo por “tener extractor”.
AlmacenamientoFoto panorámica + detalle de rack/ubicación + carga/estabilidad cuando gobierna.Capacidad estructural si no existe cálculo/placa/evidencia técnica.
ResiduosCorriente identificada + recipiente + ubicación + destino/registro cuando corresponda.Clasificación ambiental correcta sólo por color del bote.
Maquinaria / guardasActivo identificado + foto del punto de operación/transmisión + guarda/dispositivo + paro cuando corresponda + registro de mantenimiento/aislamiento aplicable.Que el operador esté capacitado o que todos los riesgos mecánicos estén cerrados.
ElectricidadTablero/desconexión accesible + identificación + cables/clavijas visibles + registro del trabajo eléctrico cuando exista mantenimiento.Diseño/capacidad de toda la instalación eléctrica ni dictamen técnico.
RuidoFuente + condición normal + tiempo de exposición + medición/evaluación cuando se active.Exposición ocupacional sólo porque “se oye fuerte” o por una lectura casual de celular.
VibraciónHerramienta/equipo + tarea + tiempo/frecuencia + evaluación cuando se active.Exposición admisible sólo por observar vibración.
Compresor / presiónPlaca/modelo/serie + presión/volumen cuando estén en placa + dispositivos + mangueras/reguladores/drenaje + servicio.Aplicabilidad o categoría NOM-020 sólo por ser compresor.
Carga manualPieza/carga real + peso si se conoce + ruta + método/personas/ayuda mecánica.Riesgo ergonómico completo sin analizar tarea real.
Descarga de aguaPunto identificado + proceso de origen + ruta/destino + caracterización/condiciones/permiso cuando se active.Que la descarga cumpla límites sólo porque llega a una coladera.
Servicios sanitarios / comedorCondición limpia/usable + agua potable + separación de proceso/químicos + privacidad respetada.Suficiencia cuantitativa o accesibilidad universal si no se evaluó el centro y su personal.
La auditoría no inventa el estándar. Sólo verifica si el área ya cumple lo que la página permanente exige, usando evidencia, revisor y fecha.
