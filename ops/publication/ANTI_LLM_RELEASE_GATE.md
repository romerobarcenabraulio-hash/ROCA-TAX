# Gate editorial anti-LLM

Una sección no se libera sólo porque sea correcta. También debe sentirse como una publicación técnica hecha por ROCA.

## Rechazo visual
Rechazar o corregir si aparece cualquiera de estos patrones sin justificación editorial:
- tarjetas repetidas;
- pseudo-dashboard;
- cajas y flechas que sólo repiten una secuencia trivial;
- iconos decorativos;
- simetría rígida aplicada a contenido desigual;
- grandes vacíos creados por plantilla;
- seis paneles donde una fotografía o una tabla resolverían mejor;
- fondos, badges o chips con apariencia SaaS;
- diagramas sin decisiones, rework, handoff o información adicional.

## Rechazo de redacción
Corregir frases genéricas como:
- “con el objetivo de garantizar”;
- “de manera adecuada”;
- “se procede a”;
- “en esta sección”;
- “es importante mencionar”;
- conclusiones que repiten el encabezado;
- lenguaje de consultoría que no ayuda a ejecutar.

## Prueba editorial
Antes de liberar, preguntar:
1. ¿Esta página resuelve una necesidad real del lector?
2. ¿La fotografía demuestra más que el elemento gráfico propuesto?
3. ¿La tabla facilita comparación o sólo fragmenta prosa?
4. ¿El diagrama agrega lógica que el texto no muestra mejor?
5. ¿Un responsable de ROCA hablaría así?
6. ¿La página podría existir en una publicación profesional sin delatar una plantilla generativa?

Si falla 5 o 6, volver a editar.

## Preservación
No homogeneizar páginas buenas para que coincidan con una plantilla nueva. La consistencia debe venir de tipografía, retícula, márgenes, numeración, terminología y jerarquía; no de repetir el mismo layout.

## Veredicto
- `PASS - EDITORIALLY CREDIBLE`
- `BLOCKED - REPAIR REQUIRED`

El Release Auditor no puede declarar `PASS - LIBERABLE` si cualquier bloque crítico permanece `BLOCKED - REPAIR REQUIRED`.
