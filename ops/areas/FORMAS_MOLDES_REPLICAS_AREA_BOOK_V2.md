## 2. Metodologías preservadas

### Formas de poliuretano
Preparar estructura/molde → encerar → orear → probar lote → dosificar → mezclar → vaciar → curar/enfriar → desmoldar/terminar.

Fuentes de entrevista conservan 20 g totales como prueba de lote y relación base 50/50 en condición cálida. Las variaciones por clima y los tiempos se mantienen en el método técnico controlado; no trasladarlos a una regla global sin contexto.

### Moldes de fibra de vidrio
Preparar forma → múltiples pasadas de cera → orear → preparar/aplicar gelcoat del taller → crear separaciones → laminar fibra → curar → abrir/terminar.

La entrevista de Omar registra alrededor de diez pasadas de cera, gelcoat de resina + talco con consistencia muy espesa y seis capas de fibra como base con posible séptima cuando requiere mayor espesor/resistencia.

### Réplicas
Preparar molde → preparar mezcla de resina/carga → vaciar/distribuir → curar/desmoldar → corregir línea/rebabas → pintar contra referencia.
