# ROCA TAXIDERMY — Paquete de cierre de campo V2

Estado: READY_TO_COLLECT / NO LIBERAR

Objetivo: pedir sólo la evidencia que mueve el cierre real. No solicitar “fotos generales” sin propósito.

## Cómo capturar

Para cada evidencia:
- área;
- Evidence ID;
- fecha;
- responsable de captura;
- qué condición demuestra;
- foto/medición/documento;
- hallazgo si no cumple;
- siguiente acción.

No fotografiar identificaciones personales, documentos sensibles completos, pertenencias privadas, vestidores o baños en uso.

## Recepción
- EVID-REC-01: panorámica de ingreso/espera + una pieza identificada + siguiente acción visible.
- Capturar estación de registro/etiquetado sin exponer datos privados.
- Confirmar quién es responsable vigente y qué evento real deja en BIWO.

## Curtiduría
- EVID-CUR-01: recorrido recepción húmeda → baños → rebajado → escurrido/secado → espera.
- EVID-CUR-02: cada químico/producto real con etiqueta legible + HDS disponible por separado.
- EVID-CUR-03: puntos donde deben medirse iluminación/ventilación/servicios.
- Fotografiar tambor, tinas, rebajadora y pateadora sólo si realmente están en uso.
- Confirmar quién prepara baños, quién opera equipo y quién libera.

## Formas / Moldes / Réplicas
- EVID-FMR-01: racks, códigos/identificación y ejemplos de forma/molde almacenados.
- EVID-FMR-02: báscula, prueba de lote, recipientes y punto de mezcla/vaciado.
- Productos A/B, resina, talco/cargas, catalizadores/desmoldante con identificación.
- Confirmar criterios reales de liberación por familia.

## Montaje
- EVID-MON-01: por estación activa, foto 3/4 completa + almacenamiento abierto + cierre de estación.
- Asociar persona ↔ estación sin asumir que el layout histórico sigue vigente.
- EVID-MON-02: zona de secado/espera con pieza identificada.
- Fotografiar punto de mezcla/uso de Bondo, fibra, adhesivo y almacenamiento real.
- Registrar dónde se hacen las tareas de detalle para posterior medición de iluminación.

## Retoque
- EVID-RET-01: punto de aerografía/pintura, solventes, pedacera y almacenamiento.
- EVID-RET-02: plano real donde se compara color/detalle para medición.
- Confirmar roster vigente y nombre correcto Valerio/Valentino.
- Fotografiar separación de resane/lijado respecto a acabado fino si existe físicamente.

## Bases
- EVID-BAS-01: base en proceso + fijación/soporte visible + condición final estable.
- Capturar corte, malla, poliuretano y material de ambientación sólo donde realmente se usan.
- Confirmar responsable vigente y frontera real con Carpintería.

## Carpintería / Corte / Embalaje
- EVID-CAR-01: sólo si el puesto existe/ya fue implementado.
- Si no existe, registrar NOT_IMPLEMENTED; no fabricar evidencia.
- Si existe: banco, corte, polvo/aserrín, madera/herrajes, embalaje y ruta de carga.

## Soldadura
- EVID-SOL-01: equipo real, consumible real, área de trabajo y protección del entorno.
- No documentar una metodología completa hasta entrevista/demostración.
- Confirmar ventilación, chispas/combustibles y equipo de extinción accesible.

## Blanqueado
- EVID-BLA-01: montaje real del recipiente, fuente de calor, nivel de agua y protección/apoyo de cuernos.
- Confirmar responsable, herramientas y si existe producto auxiliar.
- No inferir tiempo/temperatura si no se usan como criterio controlado.

## Espacios de soporte
- EVID-SUP-01: una panorámica útil por bodega, circulación, carga, residuos, oficina/BIWO y demás subespacios que realmente existan.
- Capturar rutas y obstrucciones desde perspectiva de circulación.
- No exponer pantallas BIWO con datos de clientes.

## BIWO
- EVID-BIWO-01: capturas sanitizadas de los estados/campos reales.
- Para cada evento: nombre exacto, pantalla/campo, quién lo cambia y qué evidencia queda.
- No crear nombres de estados para que coincidan con el manual.

## Qué NO pedir todavía
- sesiones fotográficas decorativas;
- documentos legales completos para incrustar en HTML;
- mediciones sin ubicación/plano/instrumento/fecha;
- evidencia duplicada que no pruebe un requisito distinto.

## Criterio de avance
El paquete se considera cerrado sólo cuando cada Evidence ID queda como:
RECEIVED / NOT_APPLICABLE-JUSTIFIED / BLOCKED-EXTERNAL.

REQUEST_DEFINED no significa evidencia recibida.
